# SMT

An offline Class 10 revision companion built around the supplied syllabus.

## What's new in v1.1
- New app identity: **SMT**
- Custom launcher logo (book + check)
- Daily revision goal
- Revision streak
- "Continue revision" shortcut
- Upcoming exam timeline
- Search topics inside each subject
- Filter topics by all / remaining / completed
- Last-revised timestamps
- Smoother WebView navigation and Android back handling
- Progress remains offline in local storage
- Urdu/Hindi subject keeps its language switch

## Build
Use the included GitHub Actions workflow. Android Studio is not required.
