# Class 10 Revision Tracker

APK-ready Android project for the Class 10 annual-exam revision tracker.

The UI is a local offline WebView app with:
- polished mobile-first dashboard
- subject progress cards
- chapter/topic checklists
- automatic percentages
- next-exam countdown
- local persistence
- Urdu/Hindi switching
- SST alternative-topic handling
- periodic-test-only topic handling
- icon-based controls, no emoji UI

The included GitHub Actions workflow builds `app-debug.apk` in the cloud, so Android Studio is not required.
